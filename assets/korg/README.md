# Supplied Korg programs

The user supplied these nine program records for default SynthMaven sounds. `sources.json` identifies each original archive and entry. Only the named Dark Chord program (Prog_253) is extracted from the 500-slot library. The THMoog executable is not redistributed or executed.

Original program-data rights remain with their respective authors. These data are separate from the firmware code licence. `tools/gen_korg_stock.mjs` uses the same `web/korg_import.js` translator as the editor to generate `firmware/src/korg_factory.h`, the editor's embedded stock records and the detailed `translated.json` report. Run it from the repository root after changing the translator or source records.

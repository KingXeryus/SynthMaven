About

SynthMaven 3.5 is a Melodee-based synthesizer and sequencer for the M-VAVE FM-1. It combines Melodee's panel graphics, sequencer, USB audio and native instrument editing with SynthMaven HYBRID/Vital translations, DX7 sounds, four-part programs, global microtuning, scenes, setlists and MIDI Learn.

Melodee is by Kerem Kilic (Ellic Studio), based on Felucca by Leo Kuroshita / Hügelton Instruments. SynthMaven also retains applicable Clipper/3dSam-derived work and third-party notices. See the release licence archive for the source attributions. Report this build's problems to SynthMaven. This project is not endorsed by M-VAVE or the upstream authors.

Programs, layers and tuning

A sound preset is one instrument sound. A program contains four sounds and their mix, split ranges and scenes. An editor library entry is a computer-side sound file; importing it does not automatically save a program. Melodee sequencer projects are a separate storage format. Do not restore a SynthMaven 3.0 whole-device backup into 3.5; keep it for rollback with its matching firmware.

Play and change sounds

  1. Press HOME. Turn ALGORITHM to change the selected part's engine.
  2. Turn PRESETS to browse that engine's sounds, wrapping at the end of its bank.
  3. Turn SELECT to choose one of the four parts. With layering off, play the selected part. With layering on, notes reach every unmuted part whose split range includes the note.
  4. Turn KNOB 1–4 for the displayed sound controls. MASTER controls both physical output and USB recording level.

The four parts share the processor, memory and voice resources. An engine's maximum voice count is not a separate guaranteed allocation for every part. Mono backing parts replace their previous note when you play a chord; complex patches and effects can reduce available polyphony.

Four-layer Home and independent drum Home

HOME switches between the four-layer program overview and the independent drum machine. Layer colors are L1 red, L2 pink, L3 light blue and L4 gray, with translucent card backgrounds and a white selection outline. Sequencer tracks use the same order. Layer numbers remain visible so color is not the only identifier.

On drum Home, SELECT or ALGORITHM chooses one of eight lanes. PRESETS or KNOB 1 selects a step. Turn KNOB 2 right to enable that step, or left to clear it. KNOB 3 sets the selected lane level; KNOB 4 changes tempo. PLAY starts or stops the independent drums. All four sound layers remain available to the keyboard. Stop playback before saving or loading programs.

Shared touch editor and playback

  1. Connect the FM-1 by USB in COMPUTER mode. In SM FM1 on iOS, choose USB cable in the connection wizard. A page marked Mock device is a demonstration and cannot play the FM-1.
  2. Open Studio → Sequencer, choose a sound part and enter a pattern. Select a numbered step to edit its notes, velocity, timing, accent, slide and chance. Play sends a start request to the connected FM-1; Stop releases sequencer playback. An empty pattern makes no sound. Check MASTER and the part's mute/level if a populated pattern is silent.
  3. Open Studio → Drums for the independent eight-lane pattern. Play and Stop here control drums independently of the melodic sequencer. Tap a step to toggle it; choose a lane to adjust level or velocity. Audition plays that lane on the FM-1. Lanes 1–4 / 5–8 and step banks keep the pads touch-sized.
  4. Perform → Layers contains the four-strip mixer: select the part, turn its pan knob, move its level fader or mute it. Expand Layering & keyboard splits for inclusive lower and upper note limits.
  5. The editor uses screen pages instead of scrolling. Use Previous page / Next page to reach additional controls. Play and Stop remain available in the bottom navigation for Sequencer and Drums. Paging, hiding panels and color changes never alter a sound.

The iOS home-screen name is SM FM1. The app icon and FM-1 startup image use the Hybrid artwork; the editor itself has no logo. The web and iOS interfaces share the same controls and USB protocol. Bluetooth is not included.

Layer switch and mixer

Hold GLO for two seconds to toggle layering. The screen shows Layered ON or Layered OFF; this gesture does not latch a held-button mode. The GLO pages also contain the layer switch.

Hold EDIT for two seconds to open and retain LAYER MIX. KNOB 1–4 control the four part volumes. SELECT chooses the part; PRESETS controls its pan; ALGORITHM sets its lower split point from A1 to A6. The editor exposes both lower and upper inclusive split limits. Press HOME to leave the mixer. Undo/redo use EDIT with OCT−/OCT+.

Save or load a named program

  1. Press SAVE to open PROGRAM.
  2. Turn SELECT or KNOB 1 to choose P1–P8; the panel shows the slot name.
  3. Use KNOB 2 or PRESETS to change the highlighted name character; ALGORITHM moves the character position. Turn KNOB 3 right twice within 1.5 seconds to LOAD. Turn KNOB 4 right twice within 1.5 seconds to SAVE the four-part program under the edited name. The first turn only arms the action; turning left cancels it.
  4. The editor provides the optional tuning override when saving. Device saves follow global tuning by default.

A fresh installation starts on P1 with layering enabled. The eight factory programs are the owner's final FM-1 edits, captured with all active native patches, part parameters, effects, splits and scenes: P1 DX7 STAGE, P2 E. Organ, P3 RHODES EP, P4 DISCO LEAD, P5 VINTAGE LEAD, P6 LEAD GUITAR, P7 ARAB STRINGS and P8 RNB BASS. The bank is a verified copy of the latest saved device programs, including the updated P1 and the already named P2 E. Organ. Saving replaces that slot's factory fallback. Autosave remains available in GLO → USB / SAVE and uses deferred, stopped-and-idle saving. Always save deliberately before switching off.

Global chromatic microtuning

Tap SEL (SCL in this guide's upstream labels). SELECT or KNOB 1 chooses the scale; KNOB 2 chooses the lower octave boundary C0–C8; KNOB 3 chooses the root; KNOB 4 enables master tuning. For C3, notes below C3 remain in equal temperament. Scale names are grouped as Western/ and Arabic/. The 14 Western scales from SynthMaven Oriental include major and minor modes, pentatonics, blues, whole tone and diminished; they use equal-tempered notes with scale-aware quantization. The 46 maqam settings apply offsets to their original chromatic keys rather than renumbering the keyboard into scale degrees.

Hold SEL for three seconds to open CUSTOM TUNE. KNOB 1 selects the key, KNOB 2 changes its offset in 10-cent steps, KNOB 3 controls Quantize all, and KNOB 4 controls Apply master tuning for the selected part. The latter is enabled for all four parts by default. Global tuning survives ordinary program changes; a program saved with an explicit tuning override can replace it.

In the editor, tap a key to select it, then use the horizontal wheel from −100 to +100 cents in 1-cent steps. Double tap an untuned key to set −50 cents; double tap an adjusted key to reset it to zero. The selected key displays its current cents. Adjusted keys are red, ordinary white/black keys retain their colors, and keys outside the scale are gray. Quantize all applies the selected root/scale to all four parts, including incoming MIDI notes.

Chords, scenes and setlists

Hold ENV for three seconds to open CHORD; a short press opens the envelope pages. Chords use the selected scale. When master microtuning applies, incompatible chord choices are hidden and open-fifth / neutral harmony choices remain available. Below the octave boundary, or for a part bypassing master tuning, ordinary equal-tempered harmony remains available.

A program contains four named scenes: compact snapshots of levels, pans, mutes, effect sends, HYBRID macros and tuning. Capture a scene in the editor's Programs & scenes section, then save the program to retain it. A setlist is an ordered list of up to 32 references to P1–P8; repeated references are allowed. Assign Scene or Setlist Next/Previous using MIDI Learn.

On HOME, hold OCT− for three seconds to load the previous program, or OCT+ for three seconds to load the next. Each hold switches once; release before repeating. Short taps change octave. Holding both retains the existing octave-reset/update gesture. In menus and dialogs, OCT−/OCT+ retain their back/confirm functions.

USB editor and MIDI Learn

On the FM-1 display, category prefixes are abbreviated W/ and A/ to preserve space for scale names. The editors retain Western/ and Arabic/.

The web editor and SM FM1 iPad app share the same dark, touch-friendly workspace. The iPad app supports landscape orientation. Perform provides quick sound, layer and tuning controls; Shape edits sound engines; Studio contains the sequencer, independent drums and Programs. Transport controls are at the bottom. Section tabs and page buttons keep controls accessible without scrolling.

Programs contains program save/load, scenes and setlists. The layer mixer and keyboard splits live in Perform → Layers. Library separates Device sounds, My library and User slots. Settings separates MIDI Learn, global controls, Display, Recording and System. Changing a view never changes sound settings.

  1. Set HOME-held menu → USB ROLE to COMPUTER.
  2. Connect a USB data cable to Chrome/Edge on a computer, or to the iPad running SM FM1 Editor. Use a powered hub when connecting a controller and FM-1 together.
  3. Tap Connect. The iOS USB wizard selects matching MIDI input/output ports together. A port may still be named Melodee FM-1; the editor verifies firmware capabilities.
  4. Perform opens first. Program Up/Down and Scene Up/Down show their current names. Quick controls, Layers and Tuning switch the lower panel without hiding the program/scene controls.

Quick controls follow the selected part. FM6 uses its own six operator envelopes: its quick panel exposes native modulator envelope timing and velocity response instead of inactive generic ADSR controls. Use the 6-OP FM page for individual operator envelopes and DX7 import. HYBRID/Vital imports belong to sound editing, not the Perform screen.

  1. Open Settings → MIDI Learn. In Connection & routing, select Controller input if routing an external controller through your computer or iPad.
  2. In Learn & actions, tap Learn new action, then press the pedal or move a controller. The editor displays the captured message.
  3. Assign an action such as Patch Up, Program Next or Scene Next. A captured CC can also control a sound parameter. Choose the target part and repeat suppression.
  4. Tap Save action to commit the assignment to the FM-1. Operate the control again; the status shows the received message and whether it matched.
  5. Add up to 16 assignments. The learned-action grid shows four at a time; use Previous actions and Next actions to access the rest without scrolling.
  6. Relearn captures a replacement message while preserving the saved mapping until Save. Cancel keeps the old mapping. Unlearn removes that assignment.
  7. Duplicate suppression accepts 0–2000 ms. A switch release rearms an intentional tap; zero disables suppression.

For a controller plugged directly into the FM-1, select PEDAL USB role and use a powered adapter or hub. Status distinguishes USB device detection from a usable MIDI interface. The same USB port cannot simultaneously host a pedal and connect as a computer peripheral: return to COMPUTER for editing or updates. Controller identity selects a supported profile when recognized; unknown devices retain generic MIDI. MCU/HUI mode and virtual MIDI port can be overridden in the editor. Device-specific modes still depend on the controller's own configuration.

USB host and powered-hub setup

The device menu calls this USB ROLE: PEDAL; it is USB MIDI host mode for keyboards, pads and pedals. It is not limited to foot pedals. COMPUTER is the device/peripheral role used by the editor and installer. Open GLO → USB / SAVE (7/10), then turn knob 3 for USB ROLE. Host mode is not retained across restart.

Controller directly into the FM-1

  1. Stop playback and disconnect the FM-1 from the computer or iPad.
  2. Power a compatible USB data hub using its own supply. Connect the MIDI controller to a downstream USB port on that hub.
  3. Connect the hub's upstream connection to the FM-1 through a suitable USB host/OTG adapter. A charging-only splitter is not a data hub. The firmware cannot supply USB VBUS power; the controller needs its own power or the hub's supply. Follow the hub manufacturer's upstream-power requirements.
  4. On the FM-1, open GLO → USB / SAVE (7/10), then turn knob 3 to change COMPUTER to PEDAL. Play a note or press the pedal. Use a class-compliant USB MIDI 1.0 controller; devices requiring a computer driver are not supported.
  5. To edit or update again, change USB ROLE back to COMPUTER, disconnect the host adapter and reconnect the FM-1 to the computer/iPad with a USB data cable. Reopen the editor connection.

One hub is supported. Hub power does not guarantee compatibility: USB-C role negotiation and the adapter wiring still matter. A USB-C to USB-A host/OTG adapter with a suitable data hub can avoid some USB-C role conflicts. Device detection is distinct from finding a usable MIDI interface. If there is no response, check controller power, data cable, role, MIDI mode and channel; reconnect or toggle the role after correcting the setup.

Editor and controller together on an iPad or computer

  1. Connect the powered hub upstream to the iPad/computer. In this arrangement the iPad/computer is the host.
  2. Connect both the FM-1 and controller to downstream hub ports. Keep the FM-1 in COMPUTER mode.
  3. Open SM FM1 or the web editor, connect the FM-1 MIDI input/output, then choose the controller input under Settings → MIDI Learn → Connection & routing.
  4. Use Learn → Assign → Save to create mappings. Confirm incoming-message and match feedback. Save the program separately after sound edits.

The FM-1 cannot be USB host and an editor-connected USB peripheral at the same time. Direct-host mappings can be prepared in COMPUTER mode, then tested in PEDAL mode. Bluetooth is excluded from 3.5.

Sound editing, filters and modulation

  1. Choose the part in Perform, then open Shape → Sound. Use the left/right engine and preset arrows to choose a starting sound.
  2. Tone, Filter, Envelopes and Modulation use two adjacent cards. Page buttons within a card expose more controls without changing the selected part.
  3. On Filter, adjust the model, cutoff, resonance and envelope amount where supported. Drag the filter preview to change cutoff/resonance. The graph is a response sketch, not a measurement of every engine's filter.
  4. On Envelopes, change attack, decay, sustain and release and inspect the parameter preview. FM6 uses native operator envelopes; use 6-OP FM for individual operators. The graph is not streamed audio.
  5. On Modulation, choose a template such as Velocity → brightness, Pressure → vibrato, Wheel → vibrato or Envelope swell. A free route is required; occupied routes are preserved. HYBRID templates are staged in its native draft: apply the draft to the part.
  6. Open Shape → Effects for the effect rack. FX Send pages are Send FX 1, Send FX 2, Send FX 3, Routing and Sends. Open Shape → Motion for paged LFO and arpeggiator controls.
  7. Save the edited sound to a user slot or library entry, or save the four-part program in Programs. Browsing and editing do not replace an explicit program save.

Custom scales and Scala files

  1. Open Tuning and select the desired root and starting scale. Tap a keyboard key, then move the fine-tuning wheel in 1-cent steps. Double-tap toggles an untuned key to −50 cents or resets a tuned key to zero.
  2. Enter a scale name in the custom-scale library and save it. Named editor scales are stored locally in that browser/app; keep exported files as backups.
  3. Use Import Scala to choose a .scl file. The importer accepts compatible octave scales with up to 12 notes, preserving the chromatic-key mapping and supported −100 to +100-cent offsets. Unsupported intervals or ambiguous mappings are rejected rather than silently changed.
  4. Recall a saved scale to apply its tuning. Export Scala writes the current scale when its pitches are ascending and its root has zero offset. Select the musical root separately.
  5. On the FM-1, choose a preset scale with SEL, then hold SEL for three seconds to fine-tune it in CUSTOM TUNE. Editing copies the preset into the custom tuning slot; KNOB 2 adjusts the selected key in 10-cent steps. The factory scale remains available.

HYBRID editing and Vital import

  1. Open Shape → Native / import. Select HYBRID / Vital, then choose Read part to edit the current native patch, or Load Vital to open a .vital JSON file.
  2. Review the translation report. Custom wavetables, spectral processing, unison, effects and unsupported routes are not reproduced. If no native waveform matches, sending is disabled until you explicitly allow native-wave approximation.
  3. Expand oscillator, filter, envelope or LFO sections to edit exact values. Under Modulation, select M1–M4 as a source, choose a destination and amount to assign a macro. Multiple routes may share a macro.
  4. Choose Apply to selected part. Draft controls do not change the device before this step. Return to the original part if you changed the selection while editing.
  5. Save to the editor library for a single sound, or save a program to preserve all four parts. Macro assignments are native patch data and are saved with the sound/program.

This first 3.5 build is USB-only. Bluetooth is a separate experimental adaptation and is not enabled by this release.

Before you install

You need Chrome or Edge, a data USB cable plugged straight into the computer (not a charge-only cable or hub if you can avoid it), and the FM-1 powered and connected.

  • Switching to another custom firmware? Choose Back up and install TransitFM1 in the installer first. Once the FM-1 shows TRANSIT, use the next firmware’s own installer. Use TransitFM1 0.1.3; 0.1 has startup and MIDI stalls, and 0.1.2 was withdrawn. For Baud Girl, install official V15 first, then use Baud Girl’s installer: its image can exceed TransitFM1’s write range.
  • Every SynthMaven firmware installation resets user settings, programs and other musical storage to factory state. Export a complete backup before installing, even when updating from this version. Keep older backups with their matching firmware; they are not a migration format. The 3.5 shared sound bank has 384 slots (U001–U384), separate from the eight four-part program slots.
  • Projects, templates and presets from Melodee 1.0 or later load. Anything saved before 1.0 shows OLD FORMAT and stays untouched until you choose to replace it. If you still have those, open and save them with 1.1.0 before updating. A backup the device cannot read is refused before anything is written.
  • Melodee is a field-testing release with no warranty. Use at your own risk.

Installing

Open the web installer in Chrome or Edge, connect the FM-1, and press Install. Leave the cable connected until writing finishes. When it succeeds, the FM-1 reports Melodee’s product identity (for example FM-1_9xxxx).

Current builds use both cores. Voice limits are shared and depend on the chosen engines, effects and four-part workload; per-engine maxima are not guaranteed simultaneously. Single-core builds have been retired. If an update leaves the unit in the loader, install a working package again using the recovery steps below.

From a terminal you can also run tools/fm1_install.py (see the project README).

Getting around

One navigation language everywhere:

  • SELECT turns the pages of the open section. On Stage it selects one of the four program parts.
  • KNOB 1 moves across (or edits a value). On list pages, KNOB 2 moves the row and KNOB 1 sets its value.
  • OCT+ enters, confirms, or opens a sheet. OCT− goes back or cancels, closing the innermost thing first (a question, a popup, a sub-screen) and only then returning to Stage.
  • On HOME, short OCT taps shift octave and a single OCT hold for three seconds changes program; both together reset octave. In menus they are Enter / Esc.
  • Named values often open a picker. Hold HOME and set PICKER POPUPS to OFF to edit those names on the knob instead. The choice is remembered. Sheets, and lists you open yourself, stay as they are. Short pages (CHORD, ENV DEST, LFO DEST, LFO 2, ARP 2) put their settings straight on the four knobs.

Holds and locks

SynthMaven shortcuts have fixed thresholds: GLO for two seconds toggles layering; EDIT for two seconds retains the four-part mixer; ENV for three seconds opens chords; SEL/SCL for three seconds opens custom tuning. A short press must not flash a long-press screen. FX retains the Melodee performance controls. Hold HOME for settings, SEQ for the pattern grid and REC to capture. See the program/tuning section above for the changed knob functions.

Sheets and undo

Hold OCT+ on pages that have a sheet (Stage, sound pages, NOTES, PATTERNS, SONG, and others) to open actions such as Init sound, Copy to…, or Sound designer.

Undo / redo:

  • Hold EDIT and press OCT− to undo. On NOTES, that undoes the last step edit first. Otherwise a finished recording take is undone first (UNDO RECORDING), and if there is none, the last sound or pattern load (or Capture).
  • While EDIT is held, OCT− undoes further and OCT+ redoes. On NOTES those keys stay on the step edits. Elsewhere OCT+ redoes the take (REDO RECORDING) before the load history.
  • A take keeps one undo: recorded notes, manual steps, length, division, swing, gate and that track’s motion, put back in one step. Playback can keep going. It is refused while that track is still recording (FINISH RECORDING). A newer take replaces it. Switching pattern or engine, or loading a project, drops it. Other tracks stay as they are. If the snapshot cannot be kept, the screen says NO RECORD UNDO MEMORY or UNDO MEMORY FULL.
  • Sound and pattern loads keep eight levels. A new edit clears redo. Recording, changing track or bank, or changing loop length starts a fresh step-edit history.
  • If a song or chain is busy, the device may ask you to stop first (STOP TO UNDO).

Stage

Step by step

  1. Press HOME until the four-part overview is shown; turn SELECT to highlight the part you want to play or edit.
  2. Turn ALGORITHM to choose its engine, then PRESETS to choose a sound within that engine. Audition with the keys.
  3. Hold GLO for two seconds to compare the selected part alone with the layered program. Press HOME again for independent drums; return HOME to the four-part overview.

Tracks

Step by step

  1. Hold EDIT for two seconds, then release it: LAYER MIX remains visible.
  2. Set part 1–4 volume with knobs 1–4. Turn SELECT to the part to pan, then PRESETS to position it left or right.
  3. Turn ALGORITHM to set the selected part’s lower split point. For an exact upper limit use Perform → Layers in the editor. Play notes on both sides of the boundary to check the split.
  4. Save the four-part program using SAVE → PROGRAM. A sound preset alone is not a backup of the complete mix.

One to four tracks, one instrument and sound each. A factory program starts with four. SELECT on HOME selects among the four program parts; the screen and its knobs take that track’s color. In the SynthMaven theme the four tracks are red, pink, light blue and gray. Knob 1 is the track color; the other three knobs are shades of it.

  • The eight factory programs already contain four parts. On HOME, hold OCT− or OCT+ for three seconds to move between programs. Use Perform → Layers in the editor to mix or mute their parts.
  • Remove track removes the selected track after a question, and only while stopped (STOP FIRST otherwise). The tracks after it move down, taking their sounds, patterns, song sections, motion and recordings with them. The last remaining track cannot be removed.
  • Stage, the mixer, PATTERNS, SONG and GLO show the tracks in use. Projects and the template keep their own track count. A project saved before this version keeps all four.
  • Each track carries its own engine, sound, patterns, transpose, effect sends, modulation and voice settings. ROOT, SCL, QNT and MPC degree are shared by the project.
  • Hold EDIT for two seconds for the four-volume mixer. GLO opens device-wide settings; its LAYERING page controls layered playback.
  • Sounding voices share one BUDGET (GLO → TUNE/CLOCK, KNOB 2): 8–32 points, default 18, remembered with the device. An idle track reserves nothing. FM6 uses 1 point per voice (up to 16). Prophet uses 2 per voice (up to eight voices a track). Most other engines use 2; the ensemble Strings engine uses 4 to leave processing headroom. These are shared limits, not four independent allocations. Melodee runs at the boot loader’s 360 MHz and does not change the clock. A unit updated while it was still at 320 MHz keeps that clock until the next power-off, and the allowance is smaller until then.

Sounds

Step by step

  1. Select the part on HOME and choose its engine and starting preset.
  2. Press EDIT for the engine’s sound pages; tap again or turn SELECT to reach the required page. Match knobs 1–4 to the four on-screen labels.
  3. Change one parameter, play a note, and compare before changing the next. The tables below explain each page’s parameters and engine-specific behavior.
  4. Use SAVE → USER for a single sound, or SAVE → PROGRAM for the complete four-part setup.

Saving sounds

Step by step

  1. Stop playback, then tap SAVE repeatedly to reach USER. Choose the destination slot with knob 1 or knob 2.
  2. Press OCT+ for the action sheet, select Save here, and confirm with OCT+. Enter the name with the keyboard or cursor/character knobs shown below.
  3. Confirm the name with OCT+, or cancel with OCT−. To recall it later, select the slot and choose Load. Saving here stores one sound, not the whole program.

Stop, tap SAVE repeatedly until USER appears, pick a slot with KNOB 1/KNOB 2, press OCT+ for the sheet (Load, Save here, Rename, Erase), choose Save here, then OCT+ again. Name it on the NAME screen.

  • Every engine shares one bank, U001–U384. A slot can hold a Prophet program, an FM6 voice, a CZ-1 tone, a SID sound, a drum kit, or any mix of those. SAVE → USER, FM6 → STORE and P5 STORE are that same bank. PRESETS lists a user sound under its own engine’s factory tones.

Common

Every tone is built from one or two lines. A line is a DCO → DCW → DCA chain: pitch, then phase-distortion (timbre), then amplitude — each with its own eight-step envelope. Common pages set how the lines combine, plus shared detune, vibrato and windows. PRESETS picks which line’s pages you are editing when you are in the per-line section.

CZ LINELINE chooses how many oscillators sound: LINE1 or LINE2 alone (the unused line’s params are drawn dim), 1+2 (both lines with their own settings), or 1+1 (two voices that both use line 1’s params — line 2’s own wave/envelopes are unused, but detune and MOD can still affect the second oscillator). Per line (LINE 1, LINE 2)

Each line has a waveform page, a touch (level / velocity) page, and three envelopes: PIT (pitch / DCO), WAV (wave depth / DCW — the phase-distortion amount that brightens or darkens the tone), and AMP (loudness / DCA). These are Casio-style rate/level multi-stage envelopes, not ADSR.

PageControls

An empty pattern takes 1, 2 or 4 bars and sets LEN (the pattern length on SEQ → Pattern); a pattern with notes takes its last LEN steps. Use EDIT + OCT− to undo; holding EDIT for two seconds opens the layer mixer. Capture pauses while a track is actively recording.
  • SEQ → TEMPO → QNT sets one recording grid for all audio and MIDI tracks, saved with the project or template. It quantizes the new take’s onsets when recording ends. OFF (default) keeps the timing you played. This is separate from scale QNT on SCL. Track GATE affects manually entered steps.
  • A project shares 1,024 timed notes across all 32 banks. RECORDING FULL leaves existing takes intact; clear or replace recorded steps to free space.

The header shows WAIT LOOP while recording waits for the selected track’s loop boundary, and ERASING during an erase pass. These stay visible while the state applies. An armed track has a REC border around its Stage row.

MIDI

Step by step

  1. Choose COMPUTER for a host computer/iPad or PEDAL for a directly attached class-compliant controller. Follow the powered-hub wiring instructions above.
  2. Set MIDI input and channel routing on GLO → MIDI/CPU. Match the controller transmit channel to the intended part/drum channel.
  3. For action mapping open editor Settings → MIDI Learn, capture the message first, assign its action, and save it. Test the received-message/match indication.
  4. Return to COMPUTER before reconnecting the editor or installer. MIDI mappings do not substitute for saving edited sounds/programs.

USB and TRS MIDI in and out.

  • ROUT chooses which MIDI channels play. CH1-4, CH5-8, CH9-12 and CH13-16 map those four channels onto tracks 1–4, and only onto tracks in use. Notes and controllers on a channel outside the group are ignored. SEL sends every channel to the selected track.
  • The DRUM channel (default 10) plays the first Drum track only when that channel is inside the ROUT group, or when ROUT is SEL. With CH1-4, channel 10 does nothing: set ROUT to CH9-12 or SEL, or set DRUM to a channel in the group (DRUM 2 plays the kit instead of track 2). With no Drum track, the channel follows ordinary routing. Set OFF to disable.
  • A note that already started still releases on the track that played it if you change ROUT so its channel is no longer included.
  • The keys send on the selected track’s channel.
  • Pitch bend, sustain, panic and clock (INT / USB / TRS) are supported. Common CCs control level, pan, cutoff/brightness, envelope times and glide. CC91 does nothing. CC93 operates KNOB1 with the MINILAB profile; otherwise it does nothing.
  • Local PLAY keeps the internal tempo until the selected MIDI input sends Start, Continue or Stop. Clock pulses alone do not take over.
  • Microtonal MIDI out sends degree addresses; an external synth needs the same tuning and mapping to match.

MIDI knobs

Hold HOME and choose MIDI KNOBS → MINILAB for an Arturia MiniLab 3 with its factory Arturia or User CC assignments. Use its MIDI port and Arturia/User program, outside arpeggiator editing; DAW/MCU mode sends a different mapping. Leave MIDI MODE → ABSOLUTE for factory settings. No controller reprogramming is needed. The profile and mode survive power-off.

KNOB1–4 follow the current page, selected track and held panel-button layers. In ABSOLUTE mode, the first value establishes the knob’s position; subsequent movement sets ordinary parameter values across their full range (0 = minimum, 127 = maximum). Navigation and special controls jog by the change in position, so connecting a controller does not jump to a different page, track or preset. For unlimited navigation with endless encoders, select a matching relative mode: REL 1 uses 63/65 for down/up (64 neutral), REL 2 uses 127/1 (0 neutral), REL 3 uses 15/17 (16 neutral). Relative movement retains each transmitted step without extra panel acceleration.

Volume responds immediately and attenuates the physical master knob: 0 mutes, 127 keeps the physical knob’s level. It also applies to computer playback. Turning MIDI KNOBS OFF restores the physical master level. MIDI volume resets to full on power-on.

USB and TRS work identically. A channel admitted by ROUT controls the selected panel track, even when that channel’s notes play another track. Mapped CCs are consumed by the panel; they do not also change a synth parameter or pass through a MIDI Track. Other CCs retain their normal behavior. Set MIDI KNOBS OFF to keep all conventional CC behavior, including CC74 brightness and CC71 resonance. The MiniLab assignments are documented in Arturia’s MIDI implementation chart.

USB audio

Step by step

  1. Connect to a computer/iPad in COMPUTER role. On GLO → USB / SAVE choose the USB AUDIO direction you need.
  2. Choose STEREO USB INPUT for the full mix or 4 TRACKS for isolated mono track stems. Select the FM-1 as the recording interface in the host app.
  3. Start with host monitoring low; raise FM-1 MASTER and check recording meters. Record a short test and play it back before a longer session.

Class-compliant, no driver. 16- or 24-bit at 44.1 kHz. The computer sees one device named Melodee, with playback and recording together:

  • Playback — play the computer through the FM-1. The computer’s volume and mute apply to that playback, on top of the MASTER KNOB. Computer playback and the monitor click stay out of recordings, and the computer’s volume does not change what is recorded.
  • Recording — STEREO by default: a copy of the master, including track effects, shared effects, pan and the output protection. Hold HOME and set USB INPUT to 4 TRACKS for four isolated mono stems, after each track’s effects and level and before the shared effects and the master. A track that is not in the song is silent on its stem.

Switch either direction off from the HOME menu’s USB AUDIO. Changing a USB option reconnects the device; reselect Melodee in your DAW if it disappears. A computer that still lists the older separate playback and recording devices needs that same reselection.

Backup and switching firmware

Step by step

  1. Before flashing, connect in COMPUTER mode and stop playback. Open Studio → Projects in the editor and choose Save backup. Keep the downloaded file outside the app/browser.
  2. Also export any editor-local library entries and named custom scales; these are not all stored in the FM-1 backup.
  3. Install firmware only after the backup finishes. A firmware flash resets previous device settings and programs to the fresh factory state.
  4. To restore, reconnect to the editor, choose Restore backup and select a compatible archive. Wait for completion, then verify all eight programs and important settings. Restore only data you intend to keep over the new factory setup.
  • Before leaving Melodee for another custom firmware, choose Back up and install TransitFM1 in the installer, then use the destination firmware’s own installer once the FM-1 shows TRANSIT. Use 0.1.3. Baud Girl requires official V15 first, then its own installer; TransitFM1 refuses images beyond its write range.
  • TransitFM1 makes no sound. It guards the next firmware’s write against interruptions except possibly its last sector. Close DAWs and other apps sending MIDI. Keep power and USB connected; if interrupted, resume the same firmware.
  • The installer’s Return to official V15 saves a complete Melodee backup first when the firmware can export one.
  • Skip backup is available when export is impossible; confirm that Melodee music, sounds and settings may be lost.
  • After reinstalling Melodee, restore from the web editor’s backup tools.
  • Older Melodee builds cannot read newer data (for example native motion events need 1.0.2 or later; the new effects and recorded takes need 1.3.0 or later; the shared 384-slot bank needs this version). Export user sounds and keep the installer’s backup before downgrading. A backup made before the preset migration is what an older version can restore.
  • Startup maintenance stays on screen while it works: the job’s name, then Keep power connected and Do not switch off. A short CHECKING SETTINGS pass can appear when saved settings need a small repair. The first start that converts older preset banks is MIGRATING PRESETS. If it cannot finish, the screen says Could not finish and Restart to retry. OCT+ (KEEP) keeps the presets and continues (preset writes stay protected until conversion succeeds). OCT− (WIPE) asks Wipe all user presets?, then OCT+ confirms. Projects, settings and factory sounds stay. A wipe that was confirmed resumes if power is lost during it.
  • RESETTING PRESETS runs when a bank or a slot cannot be read. An unreadable bank becomes empty. Unreadable slots in a bank that can be read are cleared; presets this version understands stay, including a recognized older conversion. A newer preset record this version cannot read is cleared. If the reset cannot finish, the same KEEP / WIPE choice applies.
  • RESETTING SETTINGS replaces device settings this version cannot read with the defaults (color, calibration, and the globals kept on the device). Projects stay. A template stored with those settings is not kept. Settings saved by a newer Melodee are left alone. If the write cannot finish, the screen stays until you restart; OCT+ continues, and there is no wipe.
  • The updater does not scan or move legacy Prophet banks from the abandoned flash area. Sounds that lived only in that old area are not recovered on upgrade; keep an export or a full backup if you still need them.
  • A slot saved before Melodee 1.0 shows OLD FORMAT and is left as it is until you choose to replace it. The device asks first. A backup it cannot read is refused before anything is written.

If something goes wrong

  • Install stops or fails: unplug and replug the cable, use a data cable and a direct port, open Chrome or Edge, and press Install again.
  • Three short key-light flashes mean the MIDI update loader is running; one long flash means ROM UBOOT. A unit that shows Melodee Update is in the MIDI update loader: press Install again, or run tools/fm1_install.py with a working package. An update that loses power while the application is being written comes back here on its own. Hold OCT− alone as you power on to force that rescue. Holding OCT− and OCT+ together is calibration, not rescue. The first install of this recovery, and an update that rewrites the boot stub, can still need the ROM recovery below if power is lost during that write.
  • A unit that no longer starts and appears as USB 4c4a:8057 (inquiry WL82 / UBOOT1.00) is already in ROM UBOOT. Release downloads include fm1-recover for Windows x64, Linux x64, and macOS Intel and Apple Silicon. Extract the archive, open a terminal in that folder, and run fm1-recover --info (.\fm1-recover.exe --info in Windows PowerShell). Passing a .fwsc file makes a full backup and leaves flash alone; add --write to restore application flash. The bootloader and the current saved-data regions are kept. Read RECOVERY.md in the archive for drivers and the full procedure. The tool does not force a running device into UBOOT. Melodee 1.4 does not change the system clock. A black screen left by a 1.3.0 or 1.3.1 clock change is this same UBOOT state: recover, then install.
  • Report Melodee bugs on GitHub Issues, not to Felucca or M-VAVE.

Illustrated editor walkthrough

These screenshots show the shared web/iPad interface at a 1024 × 768 landscape viewport using mock demonstration data. Factory-program names and sounds on the connected instrument differ from this mock example. The same workflows operate over USB in the browser and in SM FM1. All edits described below require a real connection to affect the instrument.

Perform: quick edits

  1. Select a part, adjust ENV or LFO and the engine controls, then use Program Up/Down or Scene Up/Down.
  2. The names show the active selection.
  3. Save edits in Programs before loading a different program.

Tone

  1. Choose an engine and preset with the side arrows.
  2. Select a card page to reach additional voice settings.
  3. Each page changes the same selected part.

Filter

  1. Select Filter, choose the supported model and adjust cutoff, resonance and envelope amount.
  2. Drag the response sketch to change cutoff and resonance together.

Envelopes

  1. Choose Envelopes.
  2. Set attack, decay, sustain and release; use the card pages for further controls.
  3. The adjacent graph previews those settings.

Modulation

  1. Choose Routes 1–2 or Routes 3–4, then source, destination and amount.
  2. Templates fill a free route.
  3. Save the sound/program after applying a template.

Effects

  1. Select the effect slot and adjust its parameters.
  2. For shared audio effects, select Send FX 1, 2 or 3, then Routing and Sends.
  3. Raise the selected part’s send and shared return to hear the effect.

LFO and arpeggiator

  1. Use LFO, LFO DEST and LFO 2 to set rate, waveform, destinations and synchronization.
  2. Use ARP and ARP 2 for pattern, range, gate, swing, probability and hold.

Native patch import

  1. Select HYBRID / Vital or Prophet.
  2. Read the selected part before editing, or import a compatible patch.
  3. Review approximations, apply to the part and save.
  4. Vital import is translation, not the Vital synthesizer running on the FM-1.

DX7 / FM6

  1. Use Voice & LFO, Operators and Load & save.
  2. Select an operator to edit its frequency and envelope.
  3. Import a DX7 SysEx file, choose a voice, send it to the selected part and save the program.

Sequencer

  1. Select a track and pattern.
  2. Tap a step, enter its note(s), length, velocity and chance, and toggle accent or slide.
  3. Pattern & tempo sets loop behavior; Motion edits automation.
  4. Play and Stop operate the connected FM-1.

Independent drum machine

  1. Tap steps to enable hits.
  2. Select a lane for level, velocity and audition; switch lane banks for the other four sounds.
  3. Set tempo and overall drum level, use Play/Stop, and Save pattern to retain edits.

Programs, scenes and setlists

  1. Select P1–P8, name the program and Save program.
  2. Enable Save tuning override only when this program should replace global tuning.
  3. Capture each scene, then save the program.
  4. Enter an ordered setlist such as 1, 3, 2, 3 and Save setlist.

Projects and full backup

  1. Save an A–D project to preserve sounds, patterns and arrangement.
  2. Load recalls that project.
  3. Save backup downloads a full archive; Restore backup restores one.
  4. Add song rows to arrange patterns and repeats, then save the project.

Global microtuning

  1. Select scale, root and the first affected octave.
  2. Enable Master tuning and the required parts.
  3. Quantize all constrains notes to the selected scale.
  4. Tap a key and drag the wheel in 1-cent steps; double-tap sets −50 cents or resets a tuned key.

Saved scales and Scala

  1. Enter a custom-scale name and Save as new.
  2. Select a saved scale and Load scale to send it to the FM-1.
  3. Import Scala reads a compatible .scl file; Export Scala makes a portable copy.
  4. Named scales are local to this browser/app.

Scale keyboard and chords

  1. Use the SCL card pages for quantization and transpose, CHORD for voicing and strum, and MPC for scale-degree pads.
  2. Master microtuning takes precedence for scale-aware pitch generation when enabled.

Library

  1. Use Device sounds to browse factory sounds, My library for local named entries, and User slots for device storage.
  2. Save current sound adds a local entry.
  3. Export library backs it up; To device slot writes a selected entry to the FM-1.

Settings

  1. Choose Global, Display, Recording or System.
  2. Global settings affect device behavior; System identifies the connected build and capabilities.
  3. Screen pages expose additional controls without scrolling.

MIDI Learn

  1. Choose Learn new action and operate the controller.
  2. After the message is captured, assign the action or parameter and Save action.
  3. The learned grid supports Relearn and Unlearn.
  4. Set repeat suppression only as needed to ignore duplicate messages without losing deliberate taps.

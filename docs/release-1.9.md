# SynthMaven 1.9 — part selection, split and pan in the layer mixer

Hold EDIT for two seconds to preview the layer mixer; at three seconds it latches and stays open after release. The four assignable knobs always control the four part volumes.

- SELECT cycles the selected part, wrapping through parts 1–4 in either direction. The selected part is highlighted.
- ALGORITHM sets that part’s split point in semitone steps, clamped from **A1 to A6** (MIDI 33–93, C4 = MIDI 60). The display includes the note name, accidental where applicable, and octave.
- PRESET/parameter adjusts the selected part’s pan, with a signed percent readout. Other parts’ pans and all four volumes are preserved.

Changing the split point enables that part’s configured Lower/Upper split zone and releases its existing notes. Lower includes the split-point note; Upper begins one semitone above it. Configure Lower/Upper, enabled state, or full-keyboard layering in GLO → LAYER ROUTE or the editor. Selecting a part does not load or replace a sound and does not change tempo. Save the program to keep its split points, zones, volume and pan.

The SEL scale browser, four standard EDIT pages, two-second preview/three-second latch timing, eight named programs, editor protocol 21 and PBK1 storage remain. GLO still toggles layering at two seconds without latching; short taps never flash its hold screen. The catalogue retains 536 calibrated audible presets and the intentionally silent USER WT slot. Physical FM1 and direct USB pedal validation remain pending.

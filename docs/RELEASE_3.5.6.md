# SynthMaven 3.5.6 — new factory programs and defaults

## Factory programs

Eight new programs, each opening on its Layer 1 lead with layering off: DX7 E.PIANO, DX RHODES, JUNO 106, E. ORGAN, DISCO LEAD, PROPHET LEAD, RETRO SYNTH and ORCHESTRA. Hold GLO to bring in the supporting layers. Every program has a little reverb and a slight chorus for movement.

## Defaults

- BUDGET now defaults to 64 points.
- MIDI now defaults to BOTH, so MIDI-only tracks accept USB and TRS together.

## Editors

On the tuning keyboard, hold a key for one second to set −50 cents or reset it to zero. This replaces the double tap, which zoomed the page on iPad.

## Installation

1. Export a complete backup first: installation resets settings and musical storage to factory defaults, including the previous factory programs.
2. Set USB ROLE to COMPUTER and install with the web installer and a data cable. Restore your backup afterwards.

## Validation and limitations

Host tests confirm the programs load, sound and do not clip. **The programs have not been auditioned, and this release has not been tested on FM-1 hardware.** A four-layer program measured a 77% CPU peak at budget 64 on an earlier build; these programs may differ. If one drops notes or crackles, lower BUDGET in GLO → TUNE/CLOCK.

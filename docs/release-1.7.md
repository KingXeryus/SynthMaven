# SynthMaven 1.7 — dedicated GLO layering screen

Holding GLO immediately replaces the current screen with **Layered ON** or **Layered OFF**, showing the current state. After **two seconds**, layering toggles once and the screen updates to the new state. Holding longer does not toggle again. Releasing GLO restores the previous screen; GLO does not latch. A short tap preserves layering. Other function buttons retain their existing three-second hold behavior.

This release retains QNT ALL, default-on per-sound master tuning, four-sound programs and the corrected Clipper by 3dSam credits from 1.6. Editor protocol 20 and the PRG2 program format are unchanged. The 537-entry catalogue retains 536 calibrated audible presets and the intentionally silent USER WT slot. Physical FM1 and direct USB pedal validation remain pending.

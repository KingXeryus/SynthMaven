SynthMaven software instrument 0.4.1 — validation

Mac: universal arm64/x86_64 Standalone, VST3 and Audio Unit built. Deployment
minimum is macOS 11.0 (verified in Mach-O load commands, not just CMake labels).
Seven CTest checks pass:
- DSP isolation, factory presets and original DSP render equivalence.
- Processor render across 5 sample rates and 5 block sizes, all factory sounds,
  host parameter/program state and editor construction.
- Eight-layer MIDI routes, controller mapping/Learn, portamento and legacy recall.
- Scala/custom scales and master tuning.
- New mixer mute/solo/master, independent faders, octave popup controls, split
  boundaries, sampler chromatic pitch/tuning, reverse/loop bounds, sample playback
  across 5 host rates and 3 block sizes, and embedded audio recall after deleting
  the original imported file.
- Actual built AU bundle registration/instantiation, 1764 parameters, MIDI input
  and finite stereo audio render. No existing installed plug-in was overwritten.
VST3 factory/module metadata generated successfully. No claim is made that every
DAW/version has been tested interactively.

The shared editor's mixer and sampler screenshots were rendered and inspected.
The existing 24 factory banks / 3383 entries remain. Sampler is an additional
user-audio source, with 16 voices per layer and portable embedded 24-bit WAV.

The iOS arm64 device app/AUv3 and arm64 simulator app/AUv3 compile successfully
with Xcode 27.1 SDKs, minimum iOS 15. The standalone embeds the AUv3 extension.
The app was launched and its mixer controls inspected in an iPadOS 27 simulator
in Device Hub. A reproducible single-scene lifecycle patch for pinned JUCE 7 is
included in prepare.py / patch-ios-scenes.py. Headless simulator RemoteIO audio
requires the Device Hub audio service to be running.
Bluetooth usage strings, native pairing panel and standalone dynamic Core MIDI
input discovery are included. Physical Bluetooth pairing, reconnect, latency,
iOS hardware audio and AUv3 host routing still require a signed device test.

No valid Developer ID signing identity is installed on the development Mac.
Mac artifacts are ad-hoc signed Local-Test builds, not notarized. iOS device
bundles are unsigned and cannot be installed as a normal signed IPA. Signing,
provisioning and TestFlight/App Store distribution remain separate steps.

0.4 additions: graphics share host parameter state; extra-oscillator A4 pitch, note-off release and stereo chorus/flanger impulse tail are covered by MixerSampler tests. Filter diagrams are illustrative, not measured transfer functions.

0.4.1 graphical coverage: shared ADSR plots for native amplitude/modulation, auxiliary oscillators and sampler; filter cutoff/resonance, LFO waveform/rate, delay echoes, reverb decay/damping, EQ, distortion transfer, stereo chorus/flanger modulation and matrix routes. Graph edits are tested against sampler attack, oscillator release and chorus-depth host parameters. Diagram responses are illustrative; no new independent native filter-envelope stage is claimed.
